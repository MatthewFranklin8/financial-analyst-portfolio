# Financial Analyst Portfolio

Live site: `https://matthewfranklin8.github.io/financial-analyst-portfolio/` (active once GitHub Pages is turned on, see setup notes below)

FP&A-focused portfolio: driver-based forecasting, variance analysis, dashboard analytics, and DCF valuation, built from public company filings and datasets.

## Structure

- `index.html`: the portfolio site itself
- `Matthew_Franklin_Resume.pdf`: resume, linked from the site
- `projects/netflix-fpa-analysis/`: Netflix FP&A model and variance memo
- `projects/finance-expense-dashboard/`: Power BI expense and income tracking dashboard
- `projects/exxonmobil-dcf/`: ExxonMobil DCF valuation and investment thesis

Each project folder has its own README with the business question, method, headline findings, and recommendation.

## Setup Notes

To make this live at `matthewfranklin8.github.io/financial-analyst-portfolio`:

1. Upload every file and folder in this package to the repository root, preserving the folder structure exactly (the `projects/` folder and its subfolders must stay intact).
2. In the repo, go to **Settings > Pages**.
3. Under **Source**, select **Deploy from a branch**, branch **main**, folder **/ (root)**. Save.
4. GitHub will publish the site within a minute or two at the URL above.
